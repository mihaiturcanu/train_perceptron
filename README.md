# About this project
I wrote this code with two goals in mind:
1. Understand how a perceptron works
2. Sharpen my C skills

I plan on extending the functionality offered by the <code>nn.h</code> header file to
be able to create NNs with multiple layers that actually do something.

# How to run the code
To run the code, download the files and run the following command in the terminal:
```
gcc nn.c -o exe_name
```
and replace <code>exe_name</code> with the desired name for the executable.

<b>Note:</b> The files should be in the same folder!
